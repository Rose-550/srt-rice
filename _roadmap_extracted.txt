AR水稻病虫害衡利不数字地图系统
核心战略：三档产品矩阵 (Good-Better-Best)
本系统采用“向后兼容”的演进策略，通过统一的算法底座适配不同消费能力的农业群
体：
位端版：
 纯手机 App/小程序，解决散户农民“零门槛”识别需求。
中端版：
 AR眼镜 + 手机边缘计算，解决种植大户“解放双手”的需求。
高端版：
 AR眼镜 + 5G/云端大模型 + 专家系统，解决科研与政府农技推广的高精度
需求。

模坐一：破冰不 MVP 构建 (Android + TFLite)
1.1 模型端侧轻量化转换
重点
熟练掌握模型导出逻辑：
.pt → ONNX → TFLite
 转换流。
学习 INT8 量化技术，在置信度与推理速度之间寻找最佳平衡点。
1.2 Android 原生建发不 CameraX
基础
掌握 Kotlin 基础：Activity 生命周期、布局管理器 (Layout)。
集成 CameraX API：实现低延迟的实时预览流与 ImageAnalysis 帧处理。
1.3 端侧推理部署
实战
学习在 Android 内存中管理 Tensor 对象，处理图像预处理（归一化、Resize）。
实现绘制引擎：将模型输出的坐标动态映射到预览 SurfaceView 上。
模坐二：应用完善不空间落位 (Concurrency + GIS)
开步并发系程：
 使用 Kotlin 协程隔离渲染线程与计算线程，确保 AR 画面不眩晕。
目标跟踪科法：
 引入 KCF 或光流法，通过“识别+跟踪”架构降低手机功耗。
数字地图集成：
 接入高德地图 Android SDK，实现 GPS 经纬度抓取与病害点位空间标记。

模坐三：AR 硬件接入不人因交云 (DP + HCI)
双屏开显：
 利用 Android Presentation API 实现手机（操作端）与眼镜（显示端）的内容分离。
AR UI 规范：
 遵循人因工程，设计边缘化、半透明、高对比度的 HUD 界面。
交云优化：
 实现脱手操作逻辑，尝试集成轻量级离线语音识别。
模坐四：云边协同不与害系统 (Backend + WebRTC)
与害指寻功能实现
利用 WebRTC 技术实现第一人称视角实时推流。专家在云端看到的画面应包含手机识
别出的“增强框”，实现跨越空间的精准指导。
Python 后端：
 使用 FastAPI 搭建高性能推理 API，承载高端版的高精度识别需求。
智能调度：
 开发“网络/算力”感知模块，根据手机性能自动切换本地与云端推理模式。
坚持“及格线+强集成”的开发理念 | 以战代练，学以致用
