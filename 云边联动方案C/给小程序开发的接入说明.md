# 给小程序开发的接入说明（10 分钟）

> 目标：把小程序识别出的**病虫害类别和置信度**，连同原图一起送到电脑端。
> 服务器已经部署好并自检通过，**你只需要改 2 处**。

---

## 一、服务器信息（已就绪，无需部署）

| 项 | 值 |
|---|---|
| 接口根地址 | `https://rice-srt.cn/relay` |
| 域名白名单 | 在小程序后台「开发管理 → 服务器域名」中，把 `https://rice-srt.cn` 加入 **request 合法域名** 和 **uploadFile 合法域名** |
| 口令 | 小程序端**不需要**（口令只给电脑端拉取用） |

**先自测接口是否可用**（浏览器直接打开，应返回 `{"ok": true, ...}`）：

```
https://rice-srt.cn/relay/api/ping
```

---

## 二、改动 1：拷一个文件

把仓库里的 `云边联动方案C/miniprogram/utils/relay.js` 复制到你项目的 `utils/` 目录。
**这是一个新文件，不覆盖你任何现有文件。**

---

## 三、改动 2：在识别完成之后加一段

找到你小程序里**拿到识别结果的那个位置**，加上：

```js
const relay = require('../../utils/relay.js');
relay.setBase('https://rice-srt.cn/relay');

relay.sendToPc({
  filePath: tempFilePath,        // 拍照/选图的临时路径
  label: '稻瘟病',                // ← 你的识别结果（类别名）
  score: 0.91,                   // ← 置信度（0~1）
  boxes: 2,                      // 可选：检测框数量
  model: 'yolov8n-onnx',         // 可选：模型标识，方便追溯
  lat: 32.0106, lng: 118.63,     // 可选：有定位就带，电脑端会自动落到地块地图
  note: '东片1号田',              // 可选：备注
}).then(r => console.log('已送到电脑端', r.id))
  .catch(e => wx.showToast({ title: '发送失败：' + e.message, icon: 'none' }));
```

**字段名不匹配怎么办？** 把 `label` 换成你实际的字段（比如 `res.className`、`result.label`），`score` 同理。

## 四、它背后走的三个接口（想自己调也行）

| 步骤 | 接口 | 说明 |
|---|---|---|
| ① 建记录 | `POST /api/records` | body: `{device, lat, lng, note}` → 返回 `{id, upload_url, finish_url}` |
| ② 传图 | `POST /api/upload/<id>` | 原始二进制 + header `X-Filename: xxx.jpg` |
| ③ 补传结果 | `POST /api/finish/<id>` | body: `{label, score, boxes, model}` |

---

## 五、怎么验证成功

1. 小程序里识别一张图 → 触发上面的调用
2. 电脑端打开程序 →「**自动巡检 → 云端同步**」→ 填 `https://rice-srt.cn/relay` + 口令 → 点「立即同步」
3. 应看到：**图进来了，类别显示为小程序识别的结果**（电脑端不会重复识别）

## 六、常见问题

| 现象 | 原因 |
|---|---|
| `request:fail url not in domain list` | 后台没加合法域名（request 和 uploadFile **都要加**） |
| 上传返回 413 | 图片超过 10MB，可让小程序先压缩 |
| 电脑端同步"新增 0 张" | 点「从头拉一遍」（同步位置已推进） |
